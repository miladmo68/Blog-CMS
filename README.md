- Create, edit and delete posts
- React Context for state
- Express and MongoDB backend
- Tailwind CSS and daisyUI

## 🚀 Getting Started

**Prerequisites:** [Node.js](https://nodejs.org/) 18 or newer · A MongoDB database (local or MongoDB Atlas)

**Clone**

```bash
git clone https://github.com/miladmo68/Blog-CMS.git
cd Blog-CMS
```

**back**

```bash
cd back
npm install
npm run dev
```

**front**

```bash
cd front
npm install
npm run dev
```

### Environment variables

Create a `.env` file (or `.env.local` for Next.js) with:

```env
MONGO_URI=
PORT=
```
